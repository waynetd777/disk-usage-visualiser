# sift

This repo uses sift, in `{{dir}}/`. Read `{{dir}}/conventions.md` once per session and follow it — the privacy rule in it is the part that matters.
Before reading unfamiliar code: `python3 {{dir}}/bin/sift.py map <path>` — it gives you sizes and symbol ranges to read instead of whole files.
Before fixing a bug: `python3 {{dir}}/bin/sift.py bug find "<error>"`. After: `sift bug add …`.
After a decision worth remembering: `sift decide "<title>" --context … --decision … --consequences …` (one command, written complete); `sift decisions` reads them back.
There are no subsystem pages here and none are to be written; `{{dir}}/conventions.md` says why.
